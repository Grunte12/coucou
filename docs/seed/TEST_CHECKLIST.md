# Seed: รายการลองเทสต์ (รอบ 2026-10-07)

## เปิดแอป

1. ปิด HubIsland หรือ Coucou ก่อน ถ้าเปิดอยู่ (กดไอคอนบน menu bar แล้วเลือก Quit)
2. รันคำสั่งนี้:

   ```bash
   scripts/run-seed.sh
   ```

   คำสั่งนี้ build แล้วเปิด Seed จากโฟลเดอร์ build เลย ไม่ได้ติดตั้งลงเครื่อง
3. ปิดแอปได้ที่ menu bar → Quit

**สิ่งที่อาจเจอครั้งแรก:**
- macOS อาจถามสิทธิ์ต่างๆ ใหม่ เพราะ bundle id ใหม่คือ `com.grunte.seed`
- อาจมีหน้าต่าง Keychain ถามสิทธิ์ใช้ credential ของ Hub ให้กด Allow ถ้ายังไม่ขึ้นข้อมูล agent ให้ pair ใหม่

## ลองตามนี้ (ติ๊กเมื่อผ่าน หรือจดสิ่งที่อยากแก้)

### Seed และ Action Ring
- [ ] ตอน notch หุบ มี Seed ตัวเดียวอยู่ซ้าย ไม่มี Mochi
- [ ] เปิด notch แล้ว Seed ไหว้ทักทาย (ครั้งแรกหลังเปิดแอป)
- [ ] กด Seed แล้วปุ่มบานออกเป็นพัด ส่วนอื่นจางลง
- [ ] ชี้เมาส์ไปทางปุ่มไหน ปุ่มนั้นเป็นสีทองพร้อมชื่อ และ Seed หันไปมอง
- [ ] คลิกเพื่อเลือก action ได้ / คลิกที่ Seed หรือที่ว่าง หรือกด Esc เพื่อปิดวง
- [ ] กด Seed ค้างแล้วปัดไปทางปุ่ม ปล่อยแล้วเลือกเลยในท่าเดียว
- [ ] Customize: เพิ่มหรือเอา action ออกได้ ลำดับตรงกับที่กด ปิดแอปแล้วเปิดใหม่ยังจำค่าไว้

### ไทม์ไลน์ agent (แท็บ Timeline)
- [ ] agent ละแถว ข้อความล่าสุดอยู่ขวาสุดติดคำว่า "now"
- [ ] สีเส้นอ่านเข้าใจ: เหลือง = รออนุมัติ, ฟ้า = กำลังทำ, เขียว = ตอบแล้ว, แดงเส้นประ = ล้มเหลว
- [ ] ชี้เมาส์แล้วเส้นสว่างขึ้น / กดที่เส้นแล้วการ์ดขึ้น / ปุ่ม Open หรือ Review พาไปหน้ารายละเอียด
- [ ] เลื่อนย้อนดูด้วย trackpad หรือล้อเมาส์ได้ลื่น ปุ่ม Now พากลับมาปัจจุบัน
- [ ] **ดูขอบล่างของ notch หลังเลื่อน ว่ามีแถบเลื่อนจางๆ โผล่ไหม** (ใน lab เห็น แต่คาดว่าเป็นเฉพาะใน lab)
- [ ] กดชื่อ agent ซ้ายมือแล้วไฮไลต์เฉพาะงานของ agent นั้น

### ลากไฟล์และเนื้อหา
- [ ] ลากไฟล์จาก Finder มาวางที่ notch แล้วเข้า Shelf และ Seed ทำท่ารับไฟล์
- [ ] ลากข้อความหรือโค้ดจาก Terminal, Claude, Cursor หรือ VS Code มาวาง ได้เป็นไฟล์ `.txt` ใน Shelf
- [ ] ลากรูปจากแชทหรือหน้าเว็บมาวาง ได้เป็นไฟล์ `.png`
- [ ] ลากลิงก์จากเบราว์เซอร์มาวาง ได้เป็นไฟล์ `.webloc`
- [ ] ลากไฟล์แนบจาก Mail หรือรูปจาก Photos มาวาง
- [ ] ลากไฟล์จาก Shelf ออกไปวางในแอป agent ได้ (เช่น Terminal ที่รัน Claude Code จะได้ path ของไฟล์)
- [ ] ลากรายการจาก Clipboard ออกไปวางในแอปอื่นได้

### Folders (ไอคอนโฟลเดอร์ล่างสุดในแถบซ้าย)
- [ ] กด Add เลือกโฟลเดอร์ได้ (หน้าต่างเลือกโฟลเดอร์ขึ้นอยู่เหนือ notch)
- [ ] เปิด Folders ค้างไว้แล้วลากโฟลเดอร์มาวาง จะเป็นการปักหมุด ส่วนไฟล์ยังเข้า Shelf
- [ ] ไฟล์เรียงจากใหม่ไปเก่า / กดโฟลเดอร์ย่อยแล้วเข้าไปได้ / Back กลับได้
- [ ] ลากไฟล์จาก Folders ไปแอป agent ได้ / ปุ่มเพิ่มเข้า Shelf และปุ่มเปิดใน Finder ใช้งานได้
- [ ] คลิกขวาที่ชื่อโฟลเดอร์แล้วเลือก Unpin ได้

### Settings ของ Seed (menu bar → Settings…)
- [ ] หน้าต่างชื่อ "Seed Settings" เป็นธีมมืดของ Seed ไม่มีอะไรของ Coucou หรือ Mochi และไอคอนแอปกับไอคอนบน menu bar เป็นเมล็ดข้าว
- [ ] General: เปิด/ปิดเสียงและปรับความดังได้ (ปล่อย slider แล้วมีเสียงตัวอย่าง) / ตั้งเวลาหุบ notch / shortcut / เปิดตอน login
- [ ] Agents → Your agent team: ขึ้นจำนวน agent ที่ online และรายชื่อจริงจาก Tincan (codex, claude-code, cursor, opencode …) ถ้าขึ้น "Not set up" ให้ส่งภาพมา
- [ ] Agents → Live from your terminal: กด Connect ที่ Codex หรือ Claude Code แล้วต้องเห็น JSON ก่อนเสมอ ยังไม่มีอะไรถูกเขียนจนกว่าจะกด Write
  - Codex: หลังกด Write ให้เปิด Codex แล้วพิมพ์ `/hooks` เพื่อ trust hook ของ Seed
  - Claude Code: เริ่ม session ใหม่ แล้วลองให้มันรันคำสั่ง ตรง notch ควรมีการ์ดขออนุญาต
- [ ] Agents → Add an agent: ใส่ชื่อ เลือกชนิด แล้วกด Create invite จะได้ข้อความ join พร้อมปุ่ม Copy (สร้าง invite จริงบน relay ของคุณ ใช้ได้ 10 นาที)
- [ ] Action Ring: เพิ่ม/เอาออก/เลื่อนลำดับได้ แล้วเปิดวงที่ notch จะเห็นตามนั้น
- [ ] Folders: Add folder / Show in Finder / Unpin ใช้ได้

### การ์ดของ agent ใน terminal (หลังต่อ hook แล้ว ดู SETUP_LATER.md)
- [ ] ขออนุญาต: การ์ดมืดของ Seed มีเส้นสีอำพันด้านบน บอกว่า agent ไหน "wants to run" คำสั่งอยู่ในกล่อง (กดเพื่อดูเต็ม) ปุ่ม Allow สีทอง, Deny, Always allow (Codex ไม่มี Always)
- [ ] Allow ต้องคลิกเท่านั้น กด Enter ไม่อนุมัติ
- [ ] คำถาม: ตัวเลือกมีเลข 1–4 กดคีย์ตัวเลขเลือกได้ เลือกหลายข้อมีวงกลมติ๊กสีทอง มีจุดบอกข้อที่เท่าไร และปุ่ม Answer in terminal
- [ ] เสร็จงาน: การ์ดเส้นเขียว ข้อความสุดท้ายของ agent ปุ่ม Open terminal / OK
- [ ] Seed: มีคำขอใหม่ → สะดุ้งแล้วเข้าท่ารอ / ตอบแล้วหรืองานเสร็จ → ยิ้มตาโค้งมีเครื่องหมายถูกสักครู่ แล้วกลับท่าปกติ
- [ ] notch เปิด → Seed เด้งโตเล็กน้อยแล้วกระพริบ / notch พับ → ยุบนิดหนึ่งแล้วกระพริบ
- [ ] หัวการ์ดเหลือแค่ปุ่มบ้าน ปุ่มเฟือง (เปิดหน้าต่าง Seed Settings) และปุ่มเสียง ไม่มีปุ่มแชตกับ + ของ Coucou แล้ว

### เสียงและความลื่น
- [ ] เสียงใหม่ของ Seed ฟังดูนุ่ม ไม่ซ้ำกับ Coucou และความดังของแต่ละเสียงพอดี
- [ ] ทุกอย่างลื่น ไม่กระตุก ไม่มีเส้นจางๆ แปลกๆ
- [ ] เปิด Reduce Motion (System Settings → Accessibility → Display) แล้วแอนิเมชันลดลงแต่ยังใช้งานได้

### ให้ agent ปรับแต่ง Seed (ทดลอง)
- [ ] ขอให้ Claude Code อ่าน `docs/seed/SEED_SKILL.md` แล้วเปลี่ยนปุ่มใน Action Ring หรือปักหมุดโฟลเดอร์ให้ จากนั้นเปิดวงหรือเข้า Folders ใหม่ ค่าที่ agent ตั้งควรขึ้นทันที
